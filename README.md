# BookTracker — этап 2: статический лендинг

Одностраничный адаптивный лендинг для проекта BookTracker — персональной библиотеки книг.

## Состав проекта

- `index.html` — семантическая HTML-разметка страницы.
- `styles.css` — адаптивные стили, визуальные макеты книжной библиотеки и карточек.
- `script.js` — демонстрационные поиск, фильтрация, сортировка и мобильное меню.

Требования к лендингу выполнены:

- чистые HTML, CSS и JavaScript без React;
- одностраничный сайт с несколькими смысловыми блоками;
- название проекта, описание проблемы и ценностное предложение;
- демонстрация основных возможностей продукта;
- иллюстрации, макеты или примеры интерфейса;
- заметный призыв к действию;
- корректное отображение на мобильных устройствах и десктопе;
- базовая доступность: семантическая разметка, подписи элементов управления, читаемый контраст;
- публикация по публичной ссылке, например на GitHub Pages.
