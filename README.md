# BookTracker — этап 2: статический лендинг

Одностраничный адаптивный лендинг для проекта BookTracker — персональной библиотеки книг.

## Состав проекта

- `index.html` — семантическая HTML-разметка страницы.
- `styles.css` — адаптивные стили, визуальные макеты книжной библиотеки и карточек.
- `script.js` — демонстрационные поиск, фильтрация, сортировка и мобильное меню.

## Что реализовано

- Название проекта, проблема, аудитория и ценностное предложение.
- Демонстрация основных функций: поиск, статусы чтения, оценки, фильтрация и сортировка.
- Примеры интерфейса и интерактивная демо-библиотека на локальных демонстрационных данных.
- Призыв к действию и навигация по секциям страницы.
- Адаптивная сетка для мобильных устройств, планшетов и десктопов.
- Семантические элементы, подписи полей, видимый фокус, ссылка перехода к основному содержимому и поддержка `prefers-reduced-motion`.
